# Agentic-AI

The canonical (original) versions live on **[keshavaai.in](https://keshavaai.in/blog)**. This repository holds source documents and drafts adapted for other places.

- [`linkedin/`](linkedin/README.md): LinkedIn drafts (status: not yet posted), with media and the short-post text.
- Caching documents in the root (`catching docs/`, `How LLMs Actually Generate Text ... .html`, `Optimizing L3 Semantic Caching.html`): earlier drafts. The corrected caching article is in `linkedin/articles/llm-caching-untangled.html` and on the website.
- Related code: [agent-controls-harness](https://github.com/kapilgupta86/agent-controls-harness), the mocked tests behind the article *Autonomy is earned*.

Views are my own. Examples are invented and illustrative.
